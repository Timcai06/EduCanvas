# 无障碍规则

- 所有交互元素（按钮、链接、表单控件）必须可通过键盘操作（Tab 聚焦、Enter/Space 触发）。
- 动态内容更新使用 `aria-live="polite"` 或 `role="alert"` 通知屏幕阅读器。
- 加载状态使用 `aria-busy="true"`，加载结束必须恢复为 `false`。
- 错误/失败状态必须提供可读的错误描述和重试入口。
- 不使用 `div` 模拟按钮——用原生 `<button>` 或添加正确的 role 和键盘处理。
- 输入框必须有 label（显式 `<label>` 或 `aria-label`）。
- 窄屏布局（320px）不产生横向溢出。
