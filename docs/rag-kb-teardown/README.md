- 最后验证时间：2026-08-05

## 这是什么

对 skillhub 上安装的第三方技能 `@user_69009747/rag-knowledge-base-builder`（v1.0.0，RAG 知识库搭建）的完整拆解研究。目的不是照搬它的技术栈，而是：

1. 摸清这个技能的真实质量（它的代码能不能跑、引用是否完整、数字是否可信）；
2. 提取它的方法论（分块策略、模型选型、检索编排、评估指标）；
3. 对照 EduCanvas 现有检索底座，判断哪些思想可以借鉴到 KM 计划的 K 线（产品知识 RAG）。

## 核心结论（先说结果）

> **这个技能"讲道理的部分有价值，但给代码的部分基本是坏的"**——全部结论都有验证证据，见各篇文档。
