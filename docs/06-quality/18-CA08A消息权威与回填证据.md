# CA08A 消息权威与回填证据

- 范围：阶段一 authority freeze、parity、backfill、rollback
- 不包含：生产切读、legacy 删除、schema migration、CA08B
- 结论边界：本文不修改计划状态，不代替唯一审查者判定 PASS

## 权威契约

| 责任                                   | 阶段一事实                                                         |
| -------------------------------------- | ------------------------------------------------------------------ |
| K12 可见消息权威                       | `chat_messages`                                                    |
| K12 lease、heartbeat、取消与恢复运行态 | `chat_messages`                                                    |
| 长期平台消息目标                       | `conversation_messages`                                            |
| 生产读取源                             | 始终为 `chat_messages`；`legacy` 与 `observe` 都不切读             |
| 回退                                   | authority stage=`legacy`，生产读=`chat_messages`，dual write=false |

`EDUCANVAS_K12_CONVERSATION_AUTHORITY_STAGE` 默认 `legacy`，阶段一严格只接受
`legacy|observe`。`observe` 只表达可运行对账，不授予平台表读权威；`platform` 与非法值在
env doctor 和运行时契约解析处都 fail closed，错误不回显原始配置值。

## Parity 证据语义

对账分页比较 conversation、operation、role、status、content、parts、failure code 与时间戳，
但 operator 结果只返回计数、稳定游标和能力状态，不返回正文。

当前没有显式 K12 projection provenance，确定性 SHA-256 ID 也不可逆，因此不能诚实地把
orphan 写成 `0`。阶段一返回：

```text
orphanDetection.status = unavailable
orphanDetection.count = null
orphanDetection.reason = k12_projection_provenance_unavailable
readCutoverEligible = false
```

这明确区分“未检测能力”和“已检测为零”。受信进程可显式调用
`DrizzleK12ConversationParityRepository.auditPage`；本轮不把它注册成通用 Graphile task，因为仓库
尚无可证明的 operator-only enqueue queue/role，不能让任意内部 enqueue caller 按 conversation ID
读取租户级计数。缺少 provenance 是切读硬门禁，不以猜测 UUID 版本替代。

## Backfill 与回退

- preview 在 repeatable-read/read-only 事务中运行；apply 在 repeatable-read/read-write 事务中运行；
- apply 只插入缺失确定性 ID，已有 mismatch 时整页零写；
- 若快照后并发 writer 抢先写入导致 `onConflictDoNothing` 返回数小于本页 missing 数，事务内抛
  稳定 invariant error，使本页全部回滚，禁止把部分插入伪报为成功；
- 默认 Worker registry 不注册回填任务；其 payload 无 apply 能力。受信 operator 只能直接调用
  `DrizzleK12ConversationBackfillRepository.applyPage`，日志与错误不含正文；
- 回退不删除已建副本。关闭 dual write 只停止新 begin 副本，已有 assistant 副本继续 settle，
  生产读取仍在 legacy。
