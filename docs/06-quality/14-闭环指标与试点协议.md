> G01 完成标准要求「指标与 Q 线采集能力一致」。因此本文档把每个指标分成
> **已可采集 / 需新增埋点 / 当前无法采集** 三类，不定义采不到的指标充数。

## 一、指标定义与采集现状

### 已可采集（现有 telemetry 指标直接支持）

| 指标 | 定义 | 采集来源 |
| --- | --- | --- |
| P50/P95 首字延迟 | 用户发问到第一个 token | `turn_ttft_ms`、`model_first_token_latency_ms` |
| P50/P95 完成延迟 | 一次 Turn 端到端 | `turn_total_ms`、`model_call_latency_ms` |
| 失败率 | Turn 失败占比 | `turn_completed_total` ÷ `turn_model_failed_total` |
| 工具失败与未知结果率 | 工具调用异常占比 | `turn_tool_failure_total`、`turn_tool_outcome_unknown_total` |
| 产物生成失败率 | 生成任务失败占比 | `artifact_generation_failed_total` |
| 限流命中 | Provider 限流次数 | `provider_rate_limits_total` |
| 检索模式分布 | 各检索路径占比 | `retrieval_mode_total` |
| 搜索可靠性 | 搜索失败与替换 | `web_search_failures_total`、`web_search_replacements_total`、`web_search_rounds_total` |
| 资料导入耗时与成功率 | 网页导入 | `web_link_import_duration_ms`、`web_link_import_total` |
| Canvas 打开耗时 | 产物打开到内容可见 | `performance-evidence.spec.ts` 台账（首开 110ms / 重开 98ms） |

### 需新增埋点（本阶段不做，作为下一阶段输入）

| 指标 | 为什么现在没有 |
| --- | --- |
| Task completion | 需先定义「一次学习任务」的服务端边界事件（当前只有 Turn 粒度） |
| 来源可追溯率 | 需统计「含引用的回答 ÷ 应含引用的回答」，后者无判定 |
| Unsupported claim rate | 需人工或裁判模型标注，不能由系统自评 |
| 练习与判分一致性 | 需重复判分比对，当前无重放机制 |
| 学习前后测效果 | 需试点设计支撑（见第二节） |
| 用户完成时间与放弃点 | 需前端行为埋点，本阶段无 |
| 单任务成本 | **telemetry 未记录 token 用量与计价**；`model-metrics` 只记延迟与错误码 |
| 用户是否理解系统限制 | 只能由访谈获得 |

### 当前无法采集

「人工介入率」在本阶段无意义——产品无人工兜底通道，任何取值都是 0，列出会制造
虚假指标。

## 二、试点协议

> **本协议本阶段不执行**（见 G04 改期说明），此处冻结的是「若要执行，必须满足什么」，
> 使后续试点不必重新设计，也防止把非试点材料当试点结论。

### 招募与授权

- 目标：6–10 名 K12 学生，覆盖小学高年级、初中、高中三段；
- 每名参与者需**监护人书面授权**，说明采集范围、保留期与删除方式；
- 参与者可随时退出并要求删除其全部数据，无需说明理由。

### 未成年人边界

- 不采集姓名、学校、住址、联系方式、人脸或声纹；
- 会话记录以随机参与者编号关联，编号与真人对照表离线保存、不入仓；
- 默认禁用 Shell、任意文件系统、Credential、任意网络与设备写能力（沿用现有边界）。

### 数据最小化与删除

- 只保留：任务脚本编号、系统事实事件、观察者记录、脱敏后的会话文本；
- 保留期 30 天；到期或参与者要求时按 `data/users/` 边界删除并记录删除回执；
- 报告中不得出现原始会话全文。

### 任务脚本

沿用[核心闭环冻结](../01-product/05-核心闭环冻结.md)的三个任务：问懂一个知识点、
动手试一次、知道自己会了没有。每人完成一节完整微课。

### 必须覆盖的场景

成功、失败、无答案、来源冲突、纠错——五类缺一不可。只跑成功路径的试点不成立。

### 中止条件

出现下列任一情况立即中止并记录：泄露他人数据、产生不安全内容、参与者出现明显
挫败或不适、系统连续三次不可用。

### 不能推出的结论

- 样本量 6–10 **不支持**任何统计显著性声明；
- 不支持「优于 ChatGpt/NotebookLM」这类比较结论（无对照组）；
- 不支持长期学习效果结论（单次接触）。

结论只能是「在该样本上观察到什么」。

## 三、纪律

- **不使用模型自评作为唯一质量指标**——G01 完成标准的硬约束；
- 不修改阈值迁就结果；
- 正向与负向结果同等记录，至少列出三个真实失败模式；
- 试点材料不含真实 Secret、未授权教材或学生隐私。
