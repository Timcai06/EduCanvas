## 当前主链事实

1. `packages/agent-runtime` 的 `TurnApplicationService` 是三条生产 Turn 路径共享的唯一应用编排入口；`AgentLoopEngine` 仍是唯一模型与工具循环。
2. Web General 通过 `WebGeneralLifecycle` 结算 assistant 消息和引用，并以 `operationTerminalWriter: 'gateway'` 明确不写 Operation 终态。
3. `GatewayService` 消费 Turn 事件后再调用 `GatewayOperationStorePort.append`；Drizzle writer 在另一事务追加 terminal event 并更新 `agent_operations`。
4. 因而“消息已结算、Gateway terminal append 失败”是现有可持久化分叉窗口。CA01 必须先冻结最小 terminal commit/reconciliation 契约，CA02 才能实施。
5. `conversation_messages` 是平台长期消息事实；`chat_messages` 在 ADR-0013 的迁移期仍承载 K12 可见消息和教学运行态。回填、切读、legacy 退役是三个独立门禁。
6. local 模式的数据主体仍是配置的本地主体（默认 `local:owner`）；账号资料、浏览器 session、effective data subject 与 Notebook owner 不得隐式互换。

## CA 文件租约边界

- Terminal：`packages/gateway-runtime`、`packages/agent-runtime` 的 Turn Application 接口，以及 `packages/db` 的 terminal adapter 和 CA 专项测试。
- Setup：根配置、`.env.example`、README、Makefile、env-check、Turbo 环境契约；不修改 Desktop 打包链。
- E2E/CI：全局 Playwright、`tests/e2e` 基线和 workflow 语义；RM 命名的资源专项用例不在 CA 所有权内。
- Identity：Web/Gateway 的 session 与 effective-subject 投影；不执行正式账号或数据归属迁移。
- Ledger：权威读源、parity、backfill、切读配置和 unified history；阶段一不切读、不删除 legacy。

共享 PostgreSQL、Migration、Playwright 与固定端口测试只有在 `CA_STATUS.md` 记录租约请求且 `REVIEW.md` 授权后运行。普通只读检查、无共享资源的定向单元测试和静态检查不占用该租约。
