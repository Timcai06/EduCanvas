## 一、最终资源产品事实

- Resource Dock 与 Studio 资源库消费同一严格 `WorkspaceResourceSummary`；Dock 恢复工作集，资源库负责完整搜索、筛选、排序和 cursor 分页。
- Source 与 Artifact 通过同一 `CanvasResource` 门禁打开；Renderer 与 `allowedActions` 由服务端投影，执行时重新鉴权，摘要不是 capability token。
- Composer 的 `+` 只添加 Source；单一 `outputPreference` 随 Turn 提交。普通 Turn 与 Live 使用同一份冻结 Context Snapshot，不以发送后的 UI 变化替换版本。
- Artifact 的 proposed、generating、ready、failed、cancelled 使用同一 `artifactId` 状态卡；ready 后同一对象进入聊天、Dock、资源库和 Canvas，不生成第二张完成卡。
- Source 原件、结构化或降级表示按权威质量事实展示；正文、媒体和 Runtime 只在打开后加载，processing 状态有界轮询并诚实收敛。
- Live 内资源预览是同一 Workspace 资源事实的只读投影；关闭、返回或 Escape 不退出语音，资源失败不改变 ASR、TTS 或 Turn 状态。

## 三、RX01 权限与安全负例

- 跨 Notebook、跨主体、成员撤销后的 detail/mutation/media 均稳定拒绝；浏览器摘要中的旧动作不能绕过 fresh repository 鉴权。
- Artifact provenance 只携带不可变 Source 身份用于展示和导航；引用 foreign Source 不产生读取权限。
- Notebook/主体切换、资源关闭和目标变化会取消或忽略迟到响应；未知 Renderer、版本、动作和恶意响应 fail closed。
- Markdown 的危险 URL、data URL 和 raw HTML 不进入可执行 DOM；Generated Image URL 限制为同源 Artifact API 路径。
- Web App manifest 拒绝外链、绝对路径、路径穿越和 secret 字段；Bridge 绑定 source、origin、runtime、Notebook、版本、hash 与序列。
- 浏览器投影不包含 Prompt、Provider raw body、对象 key、凭据或 stack。
