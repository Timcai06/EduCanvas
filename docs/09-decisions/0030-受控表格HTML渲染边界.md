# ADR-0030：受控表格 HTML 渲染边界

- 状态：`accepted`
- 日期：2026-08-16
- 负责人：@Timcai06
- 修订：[ADR-0027](./0027-Canvas多形态输出与交互运行时边界.md) §2 的 rehype-raw 禁令（仅此一条局部例外）

## 背景

ADR-0027 §2 决定「Markdown Renderer 不执行 `rehype-raw`、内联脚本、事件属性或任意网络资源」。
但结构化阅读视图（ADR-0026 决定 6 的派生表示）存在真实内容丢失：

- MinerU 产出**原生 HTML `<table>`**（`table_enable` 恒为 `false` 时的复杂表保真路径），
  且含 `colspan` 与列数不齐的畸形表；
- 渲染侧 `MessageMarkdown` 只配 `remark-gfm + remark-math + rehype-katex`，无 rehype-raw，
  react-markdown 对块级 raw HTML **整段丢弃（含内部文本）**；
- 实测 50 篇朗读语篇表格全部消失（issue #380）。

研究文档 `docs/research/2026-08/02-输入文档统一md需求与技术路线.md`（draft）已把
「rehype-raw + HTML 白名单清洗」列为既定方向，但 ADR-0027（accepted）字面禁止 rehype-raw，
两者冲突。本 ADR 在 ADR 层对齐：**对 ADR-0027 §2 开一个受控、可验证的局部例外**。

## 候选方案

| 方案           | 做法                                                             | 结论                                                                   |
| -------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------- |
| A 生成侧       | MinerU `table_enable=true` → GFM 管道表                          | 拒绝：复杂表（colspan/畸形列）保真度骤降，需重跑全部解析               |
| B 渲染侧       | `rehype-raw` + allowlist sanitizer，白名单只放表格系列与基础排版 | **采纳**：保真度最高，白名单可测试、可审计，正是研究文档既定方向       |
| C 服务端后处理 | HTML table → markdown 管道表（turndown/cheerio）                 | 拒绝：违反「不靠后处理字符串偷偷修补」约定，colspan 转管道表同样丢结构 |

## 决定

### 1. 范围：只开放结构化阅读视图，不改变聊天与笔记渲染

`rehype-raw` 只在 **ADR-0026 派生表示的结构化阅读视图**（`ReadingViewSwitcher`
structured 视图 → `MessageMarkdown`）启用。聊天消息（`MessageMarkdown` 默认路径）与
Canvas 笔记（`NoteRenderer`）保持原安全边界，**不引入 rehype-raw**。

### 2. 强制 allowlist sanitizer，无白名单不放行

启用路径必须串联 `rehype-raw` → `rehype-sanitize`（固定顺序，sanitize 在后），
schema 白名单如下：

- **允许标签**：表格系列（`table/thead/tbody/tfoot/tr/th/td/caption/colgroup/col`）+
  表格内排版（`p/br/strong/em/b/i/u/s/del/ins/sub/sup/span/ul/ol/li`）；
- **允许属性**：表格展示属性（`align/border/cellpadding/cellspacing/width/summary`、
  `colspan/rowspan/scope/valign/width`、`span`）——**不含 `style`、`class`**；
- **禁止**：`script/style/iframe/object/embed/form/input/button/textarea/select/video/
audio/canvas/svg/math` 等标签整体剥离（含内容）；事件属性（`on*`）与任意 URL 协议
  不放行（`protocols: {}`）；`id/name` 走 rehype-sanitize 默认 clobber 防护。

### 3. 白名单为共享常量，禁止组件内自定义

schema 定义在 `apps/web/features/chat/math-markdown.ts`（`tableAllowlistSchema` +
`structuredReadingRehypePlugins`），与既有插件数组同文件管理；任何组件不得在
`rehypePlugins` 里自行拼装 rehype-raw/sanitize 参数。

## 后果

- 结构化阅读视图恢复渲染 MinerU 原生 HTML 表格（含 colspan 复杂表），聊天/笔记渲染
  不受影响；
- 安全边界从「完全不渲染 raw HTML」变为「受控渲染白名单表格 HTML」；脚本、样式、
  事件、网络请求与 DOM clobbering 仍被禁止，且由单元测试锁定；
- 未来如需扩展白名单（如表内图片/链接），必须先修订本 ADR 并过 Code Owner 批准，
  不能仅改代码。

## 验证方式

1. 单元测试：表格标签与 `colspan` 保留；`script/iframe/style/onclick` 剥离；
   `allowRawHtml=false`（默认路径）仍不渲染 raw HTML；
2. CI：quality-tests 覆盖上述用例；quality-static 执行文件治理与 Prettier；
3. 结构化阅读视图对含表格的派生表示走查：表格可见、内容完整、无脚本执行。
