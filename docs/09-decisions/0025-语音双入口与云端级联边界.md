# ADR-0025：语音双入口与云端级联边界

- 状态：`accepted`
- 日期：2026-08-10
- 负责人：项目负责人
- 部分替代：[ADR-0018](./0018-实时语音输入选型与流式识别边界.md)

## 背景

原 UV 将“短句”和“课堂字幕”作为产品模式暴露给学生，但它们是工程分类，不是
K12 用户任务。语音输入还存在两种不同意图：把语音写入可编辑输入框，以及进入
连续、可插话的语音对话。两者不能共用一个自动发送语义。

## 决定

EduCanvas 提供两个独立入口：

1. **Dictation**：浏览器采集 16 kHz mono PCM16LE，停止后在内存中封装 WAV，
   通过既有 `AudioTranscriptionModelGateway` 和 SiliconFlow SenseVoiceSmall
   转成文字，追加到受控 Composer 草稿；不自动发送。
2. **Live Voice**：通过 Gateway 的现有 ticket、配额、背压和流式转录协议连接
   百炼 `paraformer-realtime-v2`；唯一 final 调用现有聊天 `onSend`，回复仍由
   General/Teaching Turn Application 和唯一 Agent Runtime 产生；回复增长时先移除
   不适合朗读的 Markdown、代码与公式语法，再按句末标点和有界软断点增量释放语义段，
   通过 `qwen-audio-3.0-tts-flash`、`longanhuan_v3.6` 合成为 24 kHz mono PCM16LE。所有语义段
   严格顺序进入同一条 Web Audio 时间轴，字幕依据实际 PCM 排期切换；首段采用更短的
   启播阈值，后续段保留更长语义，兼顾响应速度、停连和语气自然度。浏览器插话会同时
   中止在途合成、清空未播队列并取消原 Turn。

模型和音色可由服务端环境变量覆盖。默认使用百炼华北 2 业务空间专属 WSS 端点。
Provider key、原始事件和错误体止步于 `packages/model-gateway`，浏览器只接收归一化
转写事件、稳定错误和 PCM。缺少百炼配置只关闭 Live，不影响 Dictation 或文字聊天。

## 数据与安全边界

- 不新增表或 Migration，不写 Asset、对象存储、Worker 队列或浏览器持久存储。
- 音频只存在于浏览器内存、瞬时 HTTP/WS 帧和 Provider 调用期间。
- Dictation 限 60 秒、2 MiB、PCM WAV；同一界面只允许一个在途请求且不自动重试。
- 浏览器写请求继续要求同源、登录身份和已选择体验模式。
- Live 复用现有 Agent Loop；禁止在语音功能包创建第二套 Loop。

## 多模态与 Live 上下文

- Live 不建立第二套附件协议。ASR final 与当前已启用、状态为 `ready` 的
  `assetId + versionId` 快照一起提交到现有 Turn；服务端仍重新验证 Notebook 权限、
  所有权、版本和类型。处理中或失败的资料明确标注，不会静默带入本轮。
- 图片、PDF、DOCX、Markdown 和纯文本仍走现有 Asset 上传、抽取与私有存储链路；音频
  WS 不传文件。General 中图片可投影到视觉 Gateway，文档进入不可信材料上下文；Learn
  保持既有能力边界，未启用图片模型时明确拒绝而不是假装读图。
- Live 沉浸层投影本轮上下文、工具进度、引用、Artifact 结果与当前 Assistant 增量回答。
  来源和 Artifact 由 Live 内嵌只读壳复用现有 Canvas Renderer 打开，不退出语音会话、
  不复制 Renderer、Artifact 状态机或 Agent Loop；完整编辑仍交给 Workspace Canvas。
- 单条消息最多 64 个 Part（通常为 1 段文本与 63 个来源引用）；一轮最多 12 张原生图片、
  合计 24 MiB。单文件上传上限为 25 MiB，资料文本预算默认 160,000 字符，整体上下文预算
  默认 256,000 字符。所有边界都明确失败，不静默截掉用户选择的资料。

## 配置

- `DASHSCOPE_API_KEY`
- `DASHSCOPE_WORKSPACE_ID`
- `DASHSCOPE_BEIJING_WS_URL`（可选）
- `DASHSCOPE_ASR_MODEL`（默认 `paraformer-realtime-v2`）
- `DASHSCOPE_TTS_MODEL`（默认 `qwen-audio-3.0-tts-flash`）
- `DASHSCOPE_TTS_VOICE`（默认 `longanhuan_v3.6`）

旧组合 `cosyvoice-v3-flash + longanyang` 仍可通过同时覆盖上述两个变量回滚；禁止只替换
model 或 voice 造成不匹配，也不在运行时静默跨模型回退。

## 后果与验收

CI 使用 fake WebSocket 验证事件映射、唯一终态和 secret containment，不调用真实
供应商。删除 Sherpa 专用实现和依赖必须等真实 macOS 麦克风完成三轮连续对话、一次
插话和失败恢复后单独执行；在此之前保留它作为可回滚历史实现，但不再由 Gateway
组合根启用。
