# ADR-0031：Web 搜索与网页来源获取边界

- 状态：`accepted`
- 日期：2026-08-17
- 负责人：@Timcai06
- 上位决策：[ADR-0003](./0003-统一运行时与笔记本上下文.md)、[ADR-0010](./0010-资产解析异步化与解析器归位.md)、[ADR-0019](./0019-持久Web%20Runtime隔离与安全边界.md)、[ADR-0027](./0027-Canvas多形态输出与交互运行时边界.md)

## 背景

EduCanvas 已具备 URL 导入、网页正文抽取、Canvas Tier 2 Web Runtime 和单一 Agent
Loop。下一阶段还需要同时支持用户手动搜索网站、Agent 主动搜索、不可用候选自动补位和稳定
引用。若把这些能力分别做成浏览器搜索、导入抓取和 Deep Research 私有管线，会出现三套
Provider、URL 安全、去重、错误和 Source 持久化语义。

外部网页与 LLM 生成的 Web App 也有不同信任边界。LLM Web App 只运行平台接受的受控
manifest 和固定依赖，处于无同源权限、无网络的沙箱；任意网页则可能包含远程脚本、登录态、
追踪、跳转、表单和跨域请求。为外部网页重建交互预览会扩大抓取、资源镜像和运行时攻击面，
且不是 Source 导入和研究引用的必要条件。

## 候选方案

| 方案                              | 做法                                                                                         | 结论                                                                  |
| --------------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| A 统一搜索与获取底座              | 手动搜索和 Agent Tool 共用 Provider-neutral SearchService；只有实际读取的网页持久化为 Source | **采纳**：单一事实与安全边界，允许 UI 和 Agent 使用不同编排           |
| B Deep Research 独立 Agent        | 为研究功能创建第二个 Agent Loop 和专属来源库                                                 | 拒绝：破坏单一 Runtime，并复制工具、恢复和审计语义                    |
| C 浏览器直连搜索 Provider         | 前端持有 Key 并展示 Provider 原始结果                                                        | 拒绝：泄露凭据与原始响应，绕过服务端 URL 和错误投影                   |
| D 外部网页直接进入 Canvas Runtime | 把抓取的 HTML/JS 原样放入现有交互沙箱                                                        | 拒绝：远程依赖和站点行为不满足 Web Runtime 的离线、固定依赖与权限约束 |
| E 网页只导入不预览                | URL 直接创建异步 Source，正文提取后通过既有 Source 阅读器消费                                | **采纳**：缩小产品与安全范围；Canvas 继续只预览 LLM 生成的交互界面    |

## 决定

### 1. 网页导入不提供导入前预览

- 批量 URL 经服务端校验后直接创建 `link` Source 和不可变 Asset Version；
- API 返回后由 Worker 完成静态正文抽取，必要时使用受控浏览器渲染降级；
- UI 只显示逐项排队、处理中、成功、失败与重试，不请求或展示导入前摘要；
- 导入完成后的内容继续使用既有 Source 阅读器，不新增外部网页 Canvas Renderer。

### 2. Canvas 交互预览只服务平台生成的 Web App

- `web_app` 继续使用 ADR-0019/0027 定义的 Tier 2 Runtime、固定依赖和离线 CSP；
- 外部网页 HTML、脚本和远程依赖不得转换为可执行 `web_app`；
- Source 可展示安全提取的正文和已有文件派生表示，但不承诺复刻来源网站交互；
- “打开原网页”属于显式外部导航，不得伪装成 Notebook 内交互运行时。

### 3. 搜索与读取是两个独立 Tool 权限

- `web.search` 是 L0 只读发现工具，只返回规范化候选；
- `web.fetch` 是 L1 写入工具，读取成功后把网页快照持久化为当前 Notebook Source；
- 两者注册到 `packages/agent-runtime` 驱动的同一个 Tool Kernel，不创建第二个 Loop；
- 普通聊天可按需使用，Deep Research 只是在同一 Turn 上增加查询策略、预算和证据闸门。

### 4. 候选结果不等于来源或引用

- Provider 标题和摘要是不可信发现数据，不能直接成为报告证据；
- 只有经过 URL/DNS/重定向/大小/格式检查、实际读取并持久化的 Asset Version 才能获得
  `citationMarker`；
- 引用必须绑定 Notebook 内 Source、Asset Version 与 Operation ordinal；
- 不可读候选必须被替换，而不是用搜索摘要填补来源数量。

### 5. 手动搜索和 AI 搜索共用 SearchService

- 内置网站搜索由 Web BFF 调用 SearchService，浏览器只接收安全结果投影；
- Agent `webSearch` Tool 调用同一个 SearchService，但由 Agent 决定查询与候选读取；
- SearchService 支持多个 Provider、超时/限流/5xx 降级、URL 去重和来源多样性排序；
- Provider SDK 类型、Key、原始响应和内部错误止于服务端 Adapter。

### 6. 网页不可用采用候选补位，不削弱 SSRF

- 搜索阶段允许超额获取候选，读取阶段并发预检并保留 5–8 个实际可读来源；
- 403、登录墙、空正文、不支持格式、超时、限流和渲染失败使用稳定错误分类；
- 同一研究任务对连续失败域名设置冷却，并继续查询替代来源；
- 正常网络优先使用系统 DNS；仅当解析失败或全部命中 Fake-IP 时，使用固定 IP 的 DoH
  解析域名（只发送 hostname，不发送路径或查询参数），并继续校验全部答案、固定连接地址和
  核对实际 Peer；不得简单放行 `198.18.0.0/15`；
- 每次重定向和 Worker 代取资源都重新执行地址与大小边界。

### 7. Deep Research 的完成证据

- 至少完成三次不同查询；
- 至少持久化五个实际读取来源；
- 最终报告至少包含五个指向本次 Operation Source 的有效引用；
- 未达到证据门槛时返回稳定失败，不输出伪完整研究报告；
- 来源保留在 Notebook，可删除、追问和审计。

## 后果

- 网页导入路径更短，不再承担导入前预览和外部页面交互复刻成本；
- Canvas 的 Web Runtime 边界保持清晰，但用户不会在 Canvas 内操作原网站；
- 内置搜索和 Agent 搜索共享后端能力，仍保留不同的用户控制方式；
- 搜索 Provider 成功不再被当成研究成功，系统需要为可读来源补位；
- 多 Provider 与受控 egress 会增加服务端配置、可观测性和集成测试成本。

## 回退

- 可关闭内置搜索入口并只保留 URL 导入；
- 可关闭 `web.search` capability，普通 Turn 诚实降级为无联网搜索；
- 单个 Search Provider 故障时可禁用该 Adapter，不改变 Tool 与 Source 契约；
- Worker 浏览器渲染不可用时保留静态抽取与可操作失败，不回退到 API 内同步浏览器执行。

## 验证要求

1. URL 批量导入不调用 preview API，单项失败不阻断其他项；
2. SearchService Provider 切换、超时、429、5xx、去重和安全投影有单元测试；
3. 搜索候选不可读时自动补位，引用只来自持久化 Source；
4. SSRF、重定向、Fake-IP 诊断和浏览器渲染资源边界有负向测试；
5. Deep Research 的三次查询、五个来源和五个引用由确定性闸门验证；
6. 电脑浏览器验证内置搜索、批量导入、研究进度、Source 标识和引用跳转；不要求移动端或跨端证据。
