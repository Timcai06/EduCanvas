# README 图解来源

使用 [diagram-design](https://github.com/cathrynlavery/diagram-design) 的参考构图与 SVG 工作流，按本仓库代码和配色重新绘制。原工具的 MIT 许可保留于 `LICENSE.diagram-design`。

`system.html` 是自包含、可编辑图稿；`system.svg` 是矢量导出；`system.png` 是 README 使用的静态导出。`projection.json` 记录图稿检查信息。图解是逻辑说明，空间布局、设备外观和时序间距不代表真实尺寸或耗时。

配色来源：`apps/web/app/globals.css`。代码核对基线：`027ddac92c6904fc03d322680ce939235f25a63e`。
