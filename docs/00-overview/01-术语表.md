# 项目术语

## 核心概念

- **个人 Agent**：用户长期拥有、跨客户端和渠道持续工作的 Agent 主体，能够积累 Notebook 上下文并使用受控工具完成任务。每个自然人拥有一个个人 Agent；家庭与班级通过共享 Notebook 和角色授权协作，不共享 Agent 身份。
- **Education Profile**：同一个 Agent 的教育能力组合，通过 Profile、Skills、Tools、可信领域服务和可选结构化 Workflow 加载。不是第二套 Agent Loop。
- **Structured K12 Workflow**：诊断、练习、测评等有状态教学流程，只在显式进入课程时启用，不是普通教学问答的前置条件。
- **General Agent**：用户拥有的唯一长期个人 Agent，具备通用能力和教育能力。

## 系统组件

- **EduCanvas Gateway**：连接 Web、TUI、消息渠道和设备 Node 的交互控制平面，负责身份、路由、审批和事件；不同于 Model Gateway。
- **Model Gateway**：把统一模型/媒体请求适配到具体 Provider 的边界，不负责用户身份和 Notebook 路由。
- **Channel**：微信、QQ、飞书、Telegram、短信或语音等外部通信协议的适配器。
- **Node**：经 Gateway 配对后声明本地设备能力的宿主。
- **Runtime**：受控执行能力，不是第二个 Agent。

## 数据与上下文

- **Notebook**：Sources、Conversations、Artifacts、运行记录以及未来 Notebook Memory 的长期归属单位。
- **Personal Memory**：面向所有已认证个人用户的跨 Notebook 长期记忆目标，不因共享 Notebook 传播；边界已接受，产品能力尚未开放（ADR-0020）。
- **Notebook Memory**：一个学习工作空间的集体记忆目标，可按角色共享；当前尚未实现。
- **Conversation Working Memory**：当前任务的工作记忆目标，短期可压缩；当前生产组合仅使用有界最近消息，不等于完整 Working Memory。
- **Product Knowledge**：经过筛选、版本化的 EduCanvas 产品文档，可供 General Agent 按需检索。
- **K12 课程 RAG**：检索显式课程 Session 已绑定且按 Turn 冻结的知识来源；当前已实现。
- **通用 Notebook RAG**：面向 General Agent 检索当前 Notebook Sources 的目标能力；当前尚未实现。
- **Canvas**：统一工作面，不是事实数据库。

## 教学组件

- **Agent Profile**：常驻角色、目标、模型/预算、安全策略和默认能力的配置，不拥有独立 Agent 循环。
- **Skill**：按任务加载的指导或有限工作流，不直接获得可信领域写权限。
- **教学 Canvas**：承载绘本、动画、实验、代码和测验的动态区域。
- **Artifact**：Agent 生成或修改的可保存、可版本化产物；可以在 Canvas 中交互并在 Studio 中恢复。
- **知识节点**：课程图谱中的最小可学习单元。
- **掌握度**：学生对某个知识节点的结构化学习状态。
- **结构化课程状态机**：只在显式课程 Workflow 中约束诊断、讲解、示范、练习、评价和补救顺序的规则系统。

## 检索与向量

- **RAG**：先从审核知识库检索证据，再让模型基于证据生成回答。
- **Embedding 空间**：由固定模型、版本、维度、指令和归一化方式定义的向量集合。
- **Reranker**：对初步召回结果进行精细重排序的模型。

## 工程术语

- **ADR**：Architecture Decision Record，记录重大技术决策及原因。
- **BFF**：Backend for Frontend，专门为 Web 前端聚合数据的服务层。
