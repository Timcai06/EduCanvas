## 当前实现边界

### 已实现

- `packages/teaching-core` 定义 `KnowledgeRetriever` Port 和证据结构（`ports.ts:114-139`）；
- `packages/db/src/schema.ts` 已有 `knowledge_sources`、`knowledge_documents`、`knowledge_chunks`（含 `tsvector` + GIN 索引）、`knowledge_chunk_embeddings`（pgvector HNSW + cosine）和 `knowledge_embedding_runs` 表；
- `packages/db/src/knowledge-hybrid-retrieval.ts` 实现混合 pgvector + FTS 检索适配器；
- `packages/db/src/knowledge-retrieval-repository.ts` 实现 `retrieveFts()` 方法，使用 `websearch_to_tsquery` 和 `ts_rank_cd` 评分；
- `apps/web/server/teaching/teaching-tools.ts` 的 `retrieveKnowledge` 工具接入 `retrieveTeachingEvidence`；
- 每轮冻结授权 Source Version，candidate/citation 有持久化和白名单；
- PostgreSQL FTS 已实现，使用 `simple` 配置（中文需升级）；
- embedding 可选，失败时退回词法检索。

### 未实现

- General Agent 尚未接入同等的产品知识与通用检索能力；
- 冻结中文评测集尚未建立；
- Reranker 尚未接入生产；
- 教材摄取流水线尚未完整（受控资料版本可由 worker 写入，但用户上传不自动进入 K12 Source/Chunk 链路）。

## 目标检索流程

当前生产已实现 FTS、可选向量召回、RRF 和失败回退；查询改写、Reranker、中文真实教材评测与多模态检索仍是目标能力：

```text
问题分类
→ 学段/教材/知识点过滤
→ 查询改写
→ PostgreSQL全文召回
→ pgvector向量召回
→ RRF融合
→ Reranker
→ 去重与来源权威校准
→ 返回证据、页码和置信度
```

## 向量空间必须记录

- 供应商；
- 模型ID和固定Revision；
- 维度；
- 模态；
- 距离算法；
- 是否归一化；
- Query/Document Instruction；
- Instruction Hash；
- 切块器版本；
- 创建时间和启用状态。

不同模型即使维度相同，也不能混在一个向量空间。

## 教材切块

- 保留教材、年级、章节和知识点；
- 定义、示例、练习和误区分别标记；
- 采用父子块而不是只按固定Token切割；
- 图片保存OCR、描述、页码和多模态向量；
- 公式、代码和表格不能被无意义截断。

## 模型迁移

创建新空间、双写、后台回填、离线评测、线上Shadow、灰度切换、保留回滚窗口，最后再删除旧索引。

## 评测指标

- Recall@10/20；
- MRR@10；
- nDCG@10；
- 错学段召回率；
- 权威来源命中率；
- p50/p95延迟；
- 单次成本；
- 最终答案引用覆盖率。
