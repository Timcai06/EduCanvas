## 状态说明

- **PASS**：Codex 审核通过，可合并并解锁下游
- **REVISE**：目标正确但存在明确可修复缺口，仍停留在当前任务
- **BLOCK**：依赖、决策、环境或方案不成立，禁止开始下游
- **PENDING**：尚未开始执行
