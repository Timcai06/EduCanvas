## 语音产品接线门禁

语音能力仍受以下硬门槛约束：

- ADR-0018 已 accepted，WASM SIMD 路线已选定
- V02-R 已完成受控 before/after，harness 对官方 WAV 解码有可重复影响
- V02-S 已在负责人真人录音上完成双模型、Node 22/24、3 个 score、3 次重复的 72 次正式矩阵
- 当前模型没有同时纠正 `BAGGING`/`BOOSTING` 且超过 250 MiB；小模型基线含两个术语，但热词无增益且完整句转录质量不可接受
- V02-T 已完成并保持 `BLOCKED_MODEL`；需要新的模型/热词路线决策，不得提前接业务
- V02-U 已完成官方 int8 双候选 72 次矩阵：small-bilingual-int8 热词可重复增益有效，但两候选整句 WER 0.667/0.733 均超 0.35 门槛，保持 `BLOCKED_MODEL`
- V02-V 已通过现有 AudioTranscriptionModelGateway 对 SiliconFlow `FunAudioLLM/SenseVoiceSmall` 完成同一授权录音 3 次真实 smoke：输出稳定、WER=0.3333、延迟 506–975 ms，但两处 `Bagging` 均未正确，术语召回 50%；17 项失败行为证据继续通过
- V02-W 已用 SiliconFlow `TeleAI/TeleSpeechASR` 完成同一授权录音 3 次真实终稿对照：3/3 成功且非空、归一化 WER=0.3333 ≤ 0.35、延迟 1859–2341 ms，但参考句中各出现两次的 `Bagging` 与 `Boosting` 都只正确一次，按出现次数召回均为 50%。Codex 复审修正了“出现过一次即算 100%”的指标漏洞，实验结论保持 `BLOCKED_MODEL_OR_PROVIDER`；项目负责人随后明确接受该质量风险并将 V02/V03 收口为 PASS，证据本身不改写
- V04-V08、V10-V11 与 V14 已通过；下一步可并行执行 V09（模型配置组合闸门）与 V15（音频硬删除 Worker）
- 产品语音门禁仍保持关闭，不得把工程解锁宣称为实时语音输入已经完成
- 不提交模型、依赖缓存或大型音频
