## 二、架构组成

### 向量库三选一（声称 vs 实况）

- **SKILL.md 主流程**：固定用 **Milvus**（含 Partition Key 用于 RBAC 权限分级，见 `references/rbac.md`，文件缺失）。
- **rag-pipeline.md 架构图**：把向量库列为 **ChromaDB / FAISS / Milvus / Weaviate**，代码示例实际用 **Chroma**（`persist_directory="./chroma_db"`）+ OpenAIEmbeddings。
- **setup_rag.py**：支持 chromadb / faiss / milvus 三选一（默认 chromadb）。
- **不一致**：SKILL.md 与 rag-pipeline.md 之间是 Milvus vs Chroma，且文档中**不存在任何"三选一如何取舍"的对比表**——只罗列了名字。

### 配套服务（docker-compose.yml 实况）

| 服务                  | 定义方式                                                                                                                | 可用性                      |
| :-------------------- | :---------------------------------------------------------------------------------------------------------------------- | :-------------------------- |
| milvus / etcd / minio | `extends: file: ../vector-database-master/scripts/docker-compose-milvus.yml`                                            | ❌ 外部文件不存在，无法启动 |

## 三、关键决策与数据（全部原样搬表）

### 1. 分块策略矩阵（chunking-strategies.md 原文）

| 文档类型     | 推荐策略        | chunk_size    | overlap | 理由     |
| :----------- | :-------------- | :------------ | :------ | :------- |
| 通用文本     | RecursiveChar   | 512           | 50      | 简单可靠 |
| 技术文档(MD) | MarkdownHeader  | 按标题        | 0       | 保持结构 |
| 学术论文     | SemanticChunker | 自动          | 0       | 语义完整 |
| 法律合同     | 按条款          | 由结构决定    | 0       | 不可断裂 |
| 对话记录     | 按轮次          | 每轮一个chunk | 0       | 问答对   |
| 代码仓库     | 按文件+函数     | 整函数        | 0       | 逻辑单元 |

SKILL.md 正文另有"分块策略速查"表（与上表数据不一致，一并保留）：

| 场景     | chunk_size | chunk_overlap | 策略            |
| :------- | :--------: | :-----------: | :-------------- |
| 制度文档 |    256     |      50       | 小分块+按章节   |
| 技术文档 |    512     |      64       | 标准配置        |
| 长文报告 |    1024    |      128      | 大分块+语义分割 |
| FAQ      |    128     |       0       | 按QA对分割      |

高级优化（无数字）：Small-to-Big（小 chunk 128 tokens 检索、父 chunk 1024 tokens 返回）、Multi-Vector（段落级/摘要级/关键词向量）、动态重叠。

### 3. 检索效果对比表（SKILL.md 原文）

| 方案          | Top-1准确率 | Top-3准确率 | 适用场景          |
| :------------ | :---------: | :---------: | :---------------- |
| 纯向量检索    |     72%     |     85%     | 通用场景          |
| BM25+向量混合 |     81%     |     91%     | 含专有名词/缩写   |
| 混合+Rerank   |     88%     |     95%     | 高精度要求        |
| GraphRAG      |     92%     |     97%     | 多跳推理/复杂关系 |

### 4. 评估指标表（chunking-strategies.md 原文）

| 指标         | 说明                   | 目标  |
| :----------- | :--------------------- | :---- |
| 块召回率     | 相关块被检索到的比例   | > 90% |
| 块精确率     | 检索到的块中相关的比例 | > 80% |
| 上下文完整性 | 答案是否在块内         | > 95% |
| 噪声率       | 无关内容比例           | < 20% |

rag-pipeline.md 的评估管线另用 **ragas** 四指标（faithfulness、answer_relevancy、context_precision、context_recall），并给出生产 Checklist（含"响应质量监控：忠实度 < 0.7 告警"）。
