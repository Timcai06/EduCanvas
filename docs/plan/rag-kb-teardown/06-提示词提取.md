### 自带模板全文（rag-pipeline.md Phase 5，第 113-143 行）

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_messages([
    ("system", """你是一个知识库助手。请根据以下上下文回答问题。
如果上下文不足以回答，请明确说"信息不足"。

上下文：
{context}

回答规则：
1. 优先使用上下文中的准确信息
2. 引用具体数据时标注来源
3. 不确定的地方标注[需进一步确认]
"""),
    ("human", "{question}")
])

llm = ChatOpenAI(model="gpt-4o", temperature=0.1)

chain = (
    {"context": compression_retriever, "question": lambda x: x}
    | prompt
    | llm
)
```

**要点**：该模板只在 references 的 LCEL 示例管线里（且配的是 OpenAI gpt-4o API），与 SKILL.md 主路径（Ollama + RetrievalQA）不连通。

## 二、SKILL.md 主路径实际使用的提示词

SKILL.md 第 157-175 行原文（无自定义 prompt）：

```python
from langchain.chains import RetrievalQA
from langchain_community.llms import Ollama

llm = Ollama(model="qwen2.5:7b", temperature=0.1)

qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    chain_type="stuff",
    retriever=compression_retriever,
    return_source_documents=True,
    verbose=True
)
result = qa_chain({"query": "公司的年假政策是什么？"})
```

wiring 依据（[langchain v0.1.16 源码](https://github.com/langchain-ai/langchain/blob/v0.1.16/libs/langchain/langchain/chains/retrieval_qa/base.py) 第 25、75 行）：

```python
from langchain.chains.question_answering.stuff_prompt import PROMPT_SELECTOR
...
_prompt = prompt or PROMPT_SELECTOR.get_prompt(llm)
```

即默认 stuff prompt 来自 `question_answering/stuff_prompt.py`；且 Ollama 在 langchain_community 中是 BaseLLM 而非 chat model，命中 PROMPT_SELECTOR 的**默认 PromptTemplate（非 chat 变体）**。

## 三、LangChain 默认 stuff prompt 完整原文

来源：[`question_answering/stuff_prompt.py` @ v0.1.16](https://github.com/langchain-ai/langchain/blob/v0.1.16/libs/langchain/langchain/chains/question_answering/stuff_prompt.py)（与历史路径 `retrieval_qa/prompt.py` 逐字相同）

```python
prompt_template = """Use the following pieces of context to answer the question at the end. If you don't know the answer, just say that you don't know, don't try to make up an answer.

{context}

Question: {question}
Helpful Answer:"""
PROMPT = PromptTemplate(
    template=prompt_template, input_variables=["context", "question"]
)

system_template = """Use the following pieces of context to answer the user's question.
If you don't know the answer, just say that you don't know, don't try to make up an answer.
----------------
{context}"""
messages = [
    SystemMessagePromptTemplate.from_template(system_template),
    HumanMessagePromptTemplate.from_template("{question}"),
]
CHAT_PROMPT = ChatPromptTemplate.from_messages(messages)

PROMPT_SELECTOR = ConditionalPromptSelector(
    default_prompt=PROMPT, conditionals=[(is_chat_model, CHAT_PROMPT)]
)
```

## 四、四种 chain_type 默认模板简述（v0.1.16）

| chain_type | 模板文件                                                                                                                                               | 说明                                                                                                                                                                                      |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| stuff      | [stuff_prompt.py](https://github.com/langchain-ai/langchain/blob/v0.1.16/libs/langchain/langchain/chains/question_answering/stuff_prompt.py)           | 上文全文；chat 模型走 system_template 变体                                                                                                                                                |
| map_reduce | [map_reduce_prompt.py](https://github.com/langchain-ai/langchain/blob/v0.1.16/libs/langchain/langchain/chains/question_answering/map_reduce_prompt.py) | map 阶段 QUESTION_PROMPT（"Return any relevant text verbatim..."）+ reduce 阶段 COMBINE_PROMPT（变量 {summaries}/{question}，含 few-shot）                                                |
| refine     | [refine_prompts.py](https://github.com/langchain-ai/langchain/blob/v0.1.16/libs/langchain/langchain/chains/question_answering/refine_prompts.py)       | 初始 DEFAULT_TEXT_QA_PROMPT（"Given the context information and not prior knowledge, answer the question..."）+ refine 阶段 DEFAULT_REFINE_PROMPT（变量 {context_str}/{existing_answer}） |
| map_rerank | [map_rerank_prompt.py](https://github.com/langchain-ai/langchain/blob/v0.1.16/libs/langchain/langchain/chains/question_answering/map_rerank_prompt.py) | 单一 PROMPT，要求输出 score，配 RegexParser 输出 answer+score，含 few-shot                                                                                                                |

自定义 prompt 覆盖方式：`RetrievalQA.from_chain_type(..., chain_type_kwargs={"prompt": PROMPT})`；仅 stuff 接受 `prompt` 键（refine/map_reduce 分别要求 question_prompt / refine_prompt 等不同键名，见 [langchain PR #6912](https://github.com/langchain-ai/langchain/pull/6912)）。

## 五、对 EduCanvas 的启示（预览，详见 07 篇）

- 技能自带的"知识库助手"模板（上下文优先、信息不足明说、引用标来源）与我们 K 线的检索提示词方向一致，可作参考素材；
- EduCanvas 的提示词由 `packages/agent-runtime`/teaching-core 管理，不经过 LangChain 的 PROMPT_SELECTOR 机制——这是"提示词自持"而不是"框架默认"，符合 [CLAUDE.md 约束](../../../CLAUDE.md)（LangChain 不作为核心依赖）。
