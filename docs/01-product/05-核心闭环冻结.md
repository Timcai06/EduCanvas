## 一、首个核心用户

**缺少专业 AI 教师指导的 K12 学生（小学高年级至高中），在家、独自、使用电脑。**

不是教师，不是家长，不是通用知识工作者。教师与家长在本阶段只是**共享 Notebook 的
受限协作者**，不是要服务好的首个用户；他们的专属工作流（备课、批改、班级管理）
明确不在本阶段范围。

选择依据：赛题 JBGS-2026-02 面向 K12 学生；北极星目标写的是「在缺少专业 AI 教师的
情况下，**学生**仍能独立完成一节微课」。

## 二、真实场景

学生想弄懂一个 AI 通识知识点（示范主题：AI 如何识别猫和狗），身边没有能随时问的
老师。他打开 EduCanvas，在一个 Notebook 里完成一节课，并留下可回看的学习痕迹。

**不是**：课堂上教师带全班使用；不是写作业时的搜索替代；不是多人协作项目。

## 三、最常完成的三个任务

1. **问懂一个知识点** —— 提问，得到按其学段调整的、带可打开来源的解释；
2. **动手试一次** —— 在 Canvas 里用互动产物（绘本／闪卡／思维导图／分类游戏／
   Python 填空）把概念做一遍；
3. **知道自己会了没有** —— 做练习、由服务端判分、看到掌握度变化与下一步建议。

三个任务共用同一个 Agent、同一个 Notebook、同一条消息账本。

## 四、为什么不是 ChatGPT / NotebookLM / 简单 RAG

| 对比对象 | 它能做 | 它不做，而本产品必须做 |
| --- | --- | --- |
| 通用 ChatGPT | 解释知识点、生成练习 | 学段自适应不靠用户每次自己描述；判分与掌握度由**服务端确定性代码**写入，不是模型自称「你掌握了」；学习痕迹跨会话可追溯 |
| NotebookLM | 基于资料回答并给出引用 | 资料之外还要产出**可交互产物**并在其中学习；有练习、判分与掌握度闭环；产物可版本化回看 |
| 简单 RAG | 检索 + 生成 | 检索只是第 5 步；前有学段与目标，后有练习、判分、可信学习事件与下一步推荐 |

**一句话差异**：别的工具让你「得到答案」，本产品要让系统**知道你学到哪了**，并且这个
判断不是模型说的。

## 五、能力分级

本阶段四档状态定义见 [G02 能力状态](../06-quality/13-能力状态矩阵.md)。此处只冻结
**哪些属于核心**：

### 核心（主闭环，必须可用且有回归保护）

- 学段选择与学段自适应表达
- Notebook 与 Sources（上传、摄取、可用状态）
- 基于资料的回答与可打开引用
- 五类内容驱动产物：思维导图、Slides、闪卡、绘本、Markdown 文档
- 练习生成与**服务端判分**
- 可信学习事件与掌握度
- 下一步建议
- Web 浏览器入口

### 辅助（存在且可用，但不构成主闭环，失效不阻塞）

- Live Voice 与 Dictation 语音入口
- 内置网页搜索与深度研究
- 资源库搜索、筛选、排序
- 桌宠桌面外延

### 实验（可见但明确标注，不承诺稳定）

- web_app 隔离交互产物
- 代码与机器学习实验 Runtime

### 本阶段禁用或未实现（必须显式标注，不得暗示可用）

- 长期 Memory（Personal / Notebook / Conversation 三层）
- 通用 Notebook RAG
- 微信 / QQ 等未取得平台资格的渠道
- 教师备课与班级管理工作流
- 视频生成
