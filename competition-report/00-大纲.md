## 四、核心技术创新（约 6 页）

> 每项：国内外研究现状 → 我们的技术突破 → 效果指标。选三个能站住的：

1. **受控教育 Agent 架构**：通用 Agent 平台 + 教学受控接入（Profile/Skills/Tools），不建第二套 Loop；掌握度与可信学习事件集中治理。（ADR-0001/0004/0007）
2. **不可信输入的多模态内容管线**：Provider 响应验证、MinerU 派生表示不可变身份、Canvas 产物契约化（zod schema + 自动批改）。（ADR-0014/0017/0026/0027）
3. **面向未成年人的信任与安全边界**：能力信任分级、音频留存监护人单独同意、隔离 Web Runtime、secret containment。（ADR-0004/0006/0019/0022）

- 现状部分：⚠️ research 文档有引擎对比素材；"国内外研究现状"需新写文献式综述。
- 指标部分：❌ 我们没有像经纬那样的算法精度指标，需换成工程指标（测试数量、evidence 覆盖、降级行为验证）并诚实呈现——这也是差异化。
