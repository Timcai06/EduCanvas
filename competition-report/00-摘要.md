# 摘要

> 状态：初稿 v1 · 08-24（约 500 字，终稿轮按全文定稿后微调）。

教育数字化转型背景下，人工智能通识教育在基础教育阶段的普及面临优质师资不足、个性化资源匮乏、学习引导缺失三大矛盾；而直接将通用大模型暴露给未成年学生，又存在内容不可控、评价不可信、合规不达标的风险。

本项目 **EduCanvas** 面向 K12 全学段，基于大语言模型实现了"7×24 小时在线 AI 教师"对话智能体。项目的核心立意是：**用确定性的工程边界把大模型约束成一名可信的教师**——模型负责讲解与生成，判分、掌握度与学习事实由确定性代码独占维护。

系统的主要构成包括：（1）唯一 Agent Loop 的对话引擎，多入口收敛到同一执行语义，配合学习者画像实现学段自适应；（2）以 MinerU 为核心的多模态文档解析管线，教学资料经结构化解析后成为可引用、可阅读的学习来源；（3）契约化的 Canvas 互动产物体系，测验、分类游戏等产物经协议校验后由确定性代码自动批改，形成"练习—反馈—掌握度更新—推荐"的个性化学习闭环；（4）面向未成年人的分级信任边界，音频留存监护人单独同意、画像最小化收集、权限逐次重授权均落实为可测试的工程约束。

系统已完成约 27.6 万行 TypeScript 的工程实现，由 593 个测试文件、19 个端到端测试与 15 份质量证据文档守护；提供 API 对接与页面嵌入两种集成部署方案。相比现有产品，本项目的差异化在于把"可信评价"与"未成年人合规"从口号做成了数据库约束和 CI 用例。

**关键词**：人工智能通识教育；对话智能体；K12；学段自适应；多模态交互；确定性判分
