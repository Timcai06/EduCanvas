## （三）项目资源与成本管理

1. **人力**：四人全栈协同、零外包；
2. **算力**：MinerU 选纯 CPU 可跑的 pipeline/office 后端，无需 GPU 常驻；模型推理按需调用商用 API，以 `model-run-ledger` 账本逐次记账，可精确核算单次教学会话的 token 成本；
3. **软件**：全部基于开源生态（Next.js、Drizzle、Playwright 等），无商业授权负担；MinerU 许可为 Apache-2.0 附加条款（在线服务须署名，规模阈值内免费商用），合规成本低。

## （四）可行性分析

**技术可行性 ✅**：本报告第三~五章所述系统均已实现并有测试与证据支撑——这不是方案论证，而是完成度汇报。剩余缺口（学段四档、绘本）范围可控且有明确路径。

**经济可行性 ⚠️**：无硬件门槛（CPU 解析 + API 推理），边际成本主要是模型 token 费用，账本体系可精确控制预算；进校场景由校方或区域教育部门采购，付费方明确。【待补：单生年均成本估算】

**政策可行性 ✅**：未成年人保护做了分级同意与最小化收集的工程落地（音频留存监护人单独同意、画像不存出生日期）；内容安全上模型输出全程契约校验、隔离运行时执行，符合生成式 AI 服务与未成年人网络保护监管方向。

**运营可行性 ⚠️**：部署形态支持私有化（校内服务器 CPU 即可跑通全链路）与云端两种模式，API 对接/页面嵌入均有版本化协议支撑；进校周期长的行业风险见第七章风险应对。
